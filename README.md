# Midas Studio – Aim Trainer

Jsme studentský tým Midas Studio a v rámci předmětu děláme projekt **Aim Trainer**.

Jde o jednoduchou webovou aplikaci na trénink postřehu a přesnosti klikání. Aktuálně máme připravený základní návrh herního rozhraní (skóre, časomíra, životy) a v další fázi budeme programovat samotnou herní plochu, generování terčů a počítání bodů.

### Větve projektu:
* `main` – hlavní produkční větev
* `dev` – vývoj nových funkcí
* `test` – testování a opravy chyb
